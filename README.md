## 项目简介

本仓库包含两个用户脚本：

- **LinkSwift-All**：基于 Hmjz100 和油小猴的 LinkSwift 修改，支持百度网盘、阿里云盘、中国移动云盘、天翼云盘、迅雷云盘、光鸭云盘、夸克网盘、UC 网盘和 123 云盘，提供直链获取、界面美化及多种下载器推送功能。
- **UC Episode Finder**：用于 UC 网盘分享页，扫描分页文件列表，按文件名识别剧集编号，并结合文件时间确定最大集数，最后定位并高亮对应文件。它是独立脚本，不依赖 LinkSwift-All。

## 安装

选择要安装的脚本。LinkSwift-All 可直接安装；UC Episode Finder 请打开脚本文件后点击 **Raw**，再由脚本管理器安装。

### LinkSwift-All
直链获取、界面美化，支持多种下载器。

#### 正式版（脚本猫）
[安装 LinkSwift-All](https://www.tampermonkey.net/script_installation.php#url=https://scriptcat.org/scripts/code/6306/LinkSwift-All.js)

### UC Episode Finder
扫描 UC 网盘分享目录中的分页文件，定位并高亮集数最高的文件。

[查看 UC Episode Finder 源码](UC%20Episode%20Finder%20.js)

适用于 `https://drive.uc.cn/s/*` 分享页面；使用前请先登录 UC 网盘。
